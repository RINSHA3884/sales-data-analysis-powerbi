# Sales Data Analysis Using Power BI

## Project Overview

This project focuses on cleaning, transforming and analysing a sales dataset containing 1,000 rows using Microsoft Power BI.

Power Query Editor was used to handle missing values, perform data cleaning and prepare the dataset for analysis. Interactive visualizations were created to analyse order distribution across regions, identify the top five most frequently ordered products and understand profit trends over time.

DAX (Data Analysis Expressions) was used to create a calculated table, a calculated column and a measure to gain deeper insights into the sales data.

## Tools & Technologies
- Microsoft Power BI
- Power Query Editor
- DAX (Data Analysis Expressions)
- Data Visualization

## Key Features
- Data cleaning and missing value handling
- Sales data transformation
- Regional order distribution analysis
- Top 5 product analysis
- Profit trend analysis
- DAX calculated table, column and measure

## Objective

To transform raw sales data into meaningful visual insights and demonstrate practical skills in data cleaning, data modelling, DAX and business intelligence using Power BI.# sales-data-analysis-powerbi
